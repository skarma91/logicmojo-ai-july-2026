The hubA public library of models

Hugging Face is a public hub of pretrained models and datasets. Families differ by size and purpose: encoders for understanding, decoders for generation, small ones for a laptop, large ones for a server.

Pick to fitChoose a model that matches your task and your hardware. A tiny model runs on CPU in seconds; a large one needs a GPU. Start small.

LoadingTokenizer and model, together

from transformers import AutoTokenizer, AutoModel

name = "distilbert-base-uncased"
tok = AutoTokenizer.from_pretrained(name)
model = AutoModel.from_pretrained(name)

inputs = tok("a short sentence", return_tensors="pt")
outputs = model(**inputs)
  • Load both with from_pretrained, using the same name.
  • The tokenizer must be the exact one the model was trained with.
  • return_tensors="pt" gives PyTorch tensors, ready for the model.

LoadingThe mismatched-tokenizer trap

A model learns what each id means during training. Pair it with a different tokenizer and the same id points to a different token, so the input is quietly garbage, no error, just bad output.

The fixLoad the tokenizer and model by the same name, so their id-to-token maps agree.

PipelinesThe one-call path

from transformers import pipeline

clf = pipeline("sentiment-analysis")
print(clf("I loved this class"))
# [{'label': 'POSITIVE', 'score': 0.99}]
One call, three stepsA pipeline wraps tokenize, run, and decode, and picks a sensible default model for the task. It is the fast way to a result before you hand-wire the steps; pass model="..." to choose a specific model.

InferenceEval mode, and batch for speed

import torch
model.eval()
texts = ["first", "second", "third"]
batch = tok(texts, padding=True, return_tensors="pt")
with torch.no_grad():
    out = model(**batch)
  • Use model.eval() and torch.no_grad() for inference, exactly as in class 2.5 (Training in practice).
  • Pass several texts at once as a padded batch for speed, the batching idea from class 2.5.
  • No gradients, no training, just a forward pass.

InferenceReading a classification output

A classification model returns raw logits, one per label. Softmax turns them into probabilities, argmax picks the winner, and the model's id2label names it.

  • Logits (2 labels): \( (-1.5,\ 2.3) \).
  • Softmax: \( (0.02,\ 0.98) \).
  • Argmax gives id 1, and id2label[1] is "POSITIVE".
out = model(**inputs)
probs = out.logits[0].softmax(-1)
label_id = probs.argmax().item()
print(model.config.id2label[label_id])
# POSITIVE
The class 3.3 head in practiceThis is exactly the output head from class 3.3 (The Transformer): a linear layer to the labels, then softmax. A pipeline just does these lines for you.
