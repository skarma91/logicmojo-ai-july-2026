# Class 4.10: no separate micro-assignment

This class does not have its own micro. Instead, it briefs **part 2 of the Module 4
milestone**: add the fine-tuned component (from this class) to your Domain Knowledge
Assistant, and write a short, honest note, "should I have used RAG instead?", that
argues why fine-tuning was, or was not, the right lever for this behavior.

The milestone assignment lives in the module's `milestone-assignment/` folder.
